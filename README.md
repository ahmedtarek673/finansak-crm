# 🏦 Finansak CRM

A high-performance CRM system for financial services.

## Features

- **Lead Management**: Advanced tracking and qualification of financial leads.
- **Admin Dashboard**: Real-time analytics and reporting using Recharts.
- **Supabase Integration**: Secure backend and real-time database.
- **Excel Export**: Integrated XLSX support for data portability.
- **Modern UI**: Built with React 19, Tailwind CSS 4, and Lucide icons.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS.
- **Backend**: Supabase.
- **Charts**: Recharts.
- **Forms**: React Hook Form.
